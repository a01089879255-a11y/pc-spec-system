##실행 방법

별도의 서버 구축이나 패키지 설치 없이 웹 브라우저만으로 즉시 실행할 수 있습니다.

### 1. 웹 페이지로 바로 실행 (GitHub Pages)
* 배포된 GitHub Pages 주소(`https://<사용자아이디>.github.io/<저장소이름>/`)로 접속합니다.

### 2. 로컬 환경에서 직접 실행
1. 저장소에서 `index.html` 파일을 다운로드하거나 `git clone`으로 내려받습니다.
2. `index.html` 파일을 더블클릭하여 웹 브라우저(Chrome, Edge, Safari 등)로 엽니다.
> ※ 성능 시각화 차트(`Chart.js`) 및 웹 폰트 로드를 위해 인터넷 연결이 필요합니다.

## 기본 사용 순서
1. **프로그램 선택**: 학습 및 작업에 사용할 소프트웨어를 검색해 선택합니다. (복수 선택 가능)
2. **조건 설정**: 구체적인 작업 목적, 컴퓨터 예산, 성능 우선순위(`가성비` / `균형형` / `고성능`)를 입력합니다.
3. **추천 결과 확인**:
   * 호환성이 검증된 최적 부품 견적과 각 부품의 추천 이유를 확인합니다.
   * 요구 사양 대비 추천 PC의 예상 성능 그래프와 프로그램별 충족도를 비교합니다.
   * 상단 또는 결과창의 저장 버튼을 눌러 견적 리포트를 HTML 파일로 내려받을 수 있습니다.
